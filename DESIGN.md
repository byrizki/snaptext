# SnapText Design System & Brand Identity

## 1. Brand Core
- **Name:** SnapText
- **Vibe:** Friendly, Magic, Frictionless, Consumer-SaaS, Clean, Inviting.
- **Metaphors:** A magic wand, instant translation, a clean slate, soft glowing lights.
- **Strategy:** Product-Led Growth (Consumer-first with frictionless design, teasing B2B/Enterprise capabilities).

## 2. Logo & Typography
- **Iconography:** A stylized document paired with a dynamic scanning line/laser, representing instant speed and extraction.
- **Wordmark:** "SnapText" in a geometric, friendly sans-serif font (e.g., Inter, Poppins, Rounded Mplus, or Figtree).
- **Variants:**
  - Full-color horizontal: Icon left of text.
  - Favicon: Square aspect ratio, icon only.

## 3. Color Palette

Our palette balances productivity with a warm, modern tech feel, utilizing a deeply dark base with vivid, electric accents.

### Primary Accents
- **Electric Blue:** `#3b82f6` / `oklch(0.6 0.15 250)` — Used for primary buttons, active states, and scanning lasers.
- **Vibrant Purple:** `#8b5cf6` / `oklch(0.6 0.18 300)` — Used for gradients, magic/AI moments, and decorative glows.

### Neutrals (Dark Mode Focused)
- **Background (Off-Black):** `#09090b` / `oklch(0.145 0 0)` — The main canvas.
- **Card/Surface (Charcoal):** `#18181b` / `oklch(0.205 0 0)` — Floating modals, cards, inputs.
- **Borders (Slate):** `#27272a` / `oklch(0.269 0 0)` — Subtle dividers and strokes.
- **Text Primary (Crisp White):** `#fafafa` / `oklch(0.985 0 0)` — Headings and primary text.
- **Text Secondary (Muted Gray):** `#a1a1aa` / `oklch(0.708 0 0)` — Subtitles and supporting text.

### Semantics
- **Success Green:** `#10b981` / `oklch(0.65 0.15 150)` — Extraction complete, copied to clipboard.
- **Alert Red:** `#ef4444` / `oklch(0.6 0.2 25)` — Error, unreadable document.
- **Warning Yellow:** `#eab308` / `oklch(0.75 0.18 85)` — Low confidence text.

## 4. UI Design Principles (High-Fidelity)
- **Ultra-Minimalism:** Avoid cluttered sidebars. Focus entirely on the core task.
- **Soft Geometry:** Extensive use of rounded corners (squircles) for a friendly, approachable feel (`border-radius: 1rem` to `1.5rem`).
- **Typography:** Large, highly legible typography with generous line height and tracking.
- **Depth & Light:** Use soft, diffused glows and drop shadows (`box-shadow: 0 0 40px rgba(59, 130, 246, 0.15)`) to create depth rather than harsh borders.
